# Trading journal

`/dashboard` and `state/pnl.json`; the "why" is ours. Judges read P&L — this
is where we show we understood it.

Template:

```
## YYYY-MM-DD
- Live corridors / spread / caps:
- Fills: N (wARS a, wBRL b) · volume $ · edge $ · data $ · net P&L $
- Adverse fills (negative edge) and what caused them:
- Regime changes, and whether the news was right:
- Change made for tomorrow, and why:
```
